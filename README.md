# ראיון בקנדה

אתר סטטי שמכיל את המדריך המלא להתכוננות לראיון עבודה בשוק העבודה הקנדי —
14 פרקים ונספח, בעברית.

## הפעלה מקומית

```bash
npm install
npm run dev
```

## עריכת התוכן

התוכן יושב ב-`content/` — קובץ Markdown לכל פרק. אפשר לערוך אותם ישירות בלי
לגעת בקוד. אחרי עריכה, `npm run content` בונה מחדש את קבצי ה-JSON והאינדקס.

תחביר נתמך: `##` ו-`###` לכותרות, `-` לרשימות, טבלאות בפורמט Markdown רגיל,
`**מודגש**`, ותיבות הדגשה:

```
:::note
תיבה רגילה
:::

:::key
כלל מרכזי — התיבה הוורודה
:::

:::example
דוגמה או נוסח תשובה
:::
```

## לפני העלייה ראשונה

1. `npm install` ולוודא ש-`package-lock.json` נדחף ל-git (CI משתמש ב-`npm ci`).
2. להעלות את קבצי המדריך ל-`public/downloads/` בשמות:
   `madrich-raion-canada.docx` ו-`madrich-raion-canada.pdf`.
3. אופציונלי: קבצי גופנים ל-`public/fonts/` (ראו README שם).
4. ב-GitHub: Settings → Pages → Source: **GitHub Actions**.

## פריסה

כל דחיפה ל-`main` מפעילה בנייה ופריסה אוטומטית ל-GitHub Pages.
